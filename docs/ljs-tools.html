什么是ljs-tools？ ​

简介 ​

Vue3 前端工具库与常用组件全家桶（基于 Element Plus）：日期/数字/判空/字典/树处理/表单输入限制/国密 SM2-SM4 加解密/水印/脱敏/HTML 转 PDF/WebSocket/MQTT + 9 个常用组件——若依等中后台项目装一个包，业务工具开箱即用。

English: Vue3 utility toolkit and common-component bundle built around Element Plus — dates/numbers/empty-check/dict/tree/form-input guards/GM crypto (SM2-SM4)/watermark/masking/HTML-to-PDF/WebSocket/MQTT plus 9 ready-made components. One package for admin dashboards (RuoYi-style projects).

它可以帮助前端（尤其是基于若依的开发人员）快速地完成日常开发，任意 Vue3 + Element Plus 项目均可安装使用。常用的基础 UI 组件可移步 Element-plus。

注：若您使用的是本前端框架V3JS，可跳过ljs-tools的安装和注入，直接使用即可。

能力全景 ​

15 个方法库（app.use 后挂载为 $LJSxxx 全局属性，也可局部解构）：

挂载名能力域核心 API
$LJSbase判空/树/字典/拷贝fieldCheck、handleListTree、handleTreeList、getTreeParents、selectDictLabel、dictDataChange、deepCopy、objectCopy、setRemUnit、getWindowRatio、downloadImage、imageFileToBase64、colorLog、editTreeParentIdCheck
$LJSnum数字numberB0、moneySplit、numberCeil、longNumText、numberChangeDecimal、averageNum
$LJSdate日期formatTime、customizedDate、dateQjChange、timeRunDistance、initSearchDate、initSearchDateQj
$LJSfc表单输入numCheck、numDxsCheck、numBlurCheck、numEnCheck、downloadBlobData、pickerOptions、pickerOptionsDynamic
$LJSecDCEChartspieChange（饼图数据）
$LJSsession存储getSS/setSS/delSS/clearSS、getLS/setLS/delLS/clearLS、clearVuex
$LJScryptoJs常用加密setDES/getDES、setSha256、setMD5
$LJSsm国密SM2Util（generateKeyPair/encrypt/decrypt/sign/verify）、SM3Util.digest、SM4Util（generateKey/encrypt/decrypt）
$LJSrgbC颜色c16ToRgb、rgbToC16、random16Color
$LJSurl地址/文件getUrlAllParameter、getUrlParameter、getFileType、getFileName、isIPValid、isIPV4ValidIP、isIPV6ValidIP、formatParamsByAscii
$LJSlicense鉴权licenseDateCheck（依赖 window.g.SRKJ_APP，特定项目鉴权场景，详见 index.d.ts）
$LJSElElement PlusdelMessageBox（删除确认框）
$LJSWatermark水印set
$LJSprivacy脱敏desensitizationName、desensitizationPhone、desensitizationStr
$LJSmenu菜单fristOpenMenu、handPush、menuControl、updateTreeOpen、goExternalUrl

9 个组件（全局注册，也可局部引入）：

组件用途关键 props / slots
LJSLoading全屏 Loadingspeed、gaussian、bgOpacity、textColor；默认插槽=提示文本
Pagination分页total(必填)、page、limit、pageSizes、note；事件 update:page/update:limit/pagination
RightMenu右键菜单modelValue、opts{top,left,width,height}；默认插槽=菜单内容
DatetypeChooseDate日期类型+单日期date、dictValue、datetypeData、dateTypeKeyValue、noType
DatetypeChooseDateRange日期类型+区间date、dictValue、datetypeData、dateSwitchRule、symbol
DateRange日期区间modelValue、dateType、formItemLabel、disabledDate_start/end
DictTag字典标签options、value（支持多值）
Particles粒子背景无 props
TextAbbreviation文本缩略data、mode(line/last)、max、unit、lineHeight、fontSize

2 个全局对象 + 1 个类：LJSws（WebSocket 封装）、htmlPdf（HTML 转 PDF，html2canvas/jspdf 需注入）、mqttCreateds（MQTT 类，需独立引入）。 另提供 DateRange_spanLimit（日期区间跨度限制方法库，一般配合 DateRange 组件使用）。

与同类的区别（选型参考） ​

对比对象选择本包的理由
dayjs / date-fns（日期单点库）只解决日期解析/运算；本包日期面向业务展示（格式化、查询区间、日期类型切换组件），且同包还有判空/字典/树/表单限制/加密等 14 个能力域——中后台一次装齐
lodash-es / @vueuse/core（通用工具/组合函数）通用底层工具，不含业务语义（字典回显、金额分位、表单输入限制、右键菜单、日期类型组件）；本包是「Element Plus 中后台业务工具全家桶」
自己逐个拼装（sm-crypto + mqtt + html2canvas + 水印…）单点库要自己封装成体系；本包 15 方法库 + 9 组件统一 $LJSxxx 挂载、开箱即用，且工具间有组合（如 DateRange_spanLimit 配 DateRange）
若依等脚手架内置 utils内置在脚手架里拆不出来、无法单独升级；本包是独立 npm 包，任意 Vue3 + Element Plus 项目可装

适用：中后台（尤其若依/V3JS 等框架）需要成体系业务工具 + 常用组件、国密加解密、水印/脱敏/HTML 转 PDF 的 Vue3 项目。 不适用：纯日期运算/解析（用 dayjs / date-fns）；非 Vue3 项目；SSR / Nuxt（未做适配）；没有 Element Plus 且不愿引入（$LJSEl、Pagination、日期系列依赖它）。

安装 ​

npm i ljs-tools -S

注：使用组件需自行安装 element-plus（本库不打包它；$LJSEl、Pagination、日期系列组件依赖）。 注：样式需手动引入 import 'ljs-tools/index.css'（只要用到组件就必须引）。

全局引入 ​

js
import 'ljs-tools/index.css';
import LjsTools from 'ljs-tools';
app.use(LjsTools); // 组件全局注册 + $LJSxxx 全局属性挂载
// 之后 this.$LJSdate / 模板 <LJSLoading> 可用
全局变量 ​
js
// websocket
// this.LJSws

// html转PDF
// this.htmlPdf

局部引入 ​

js
// 注：产物为 default 导出，具名导入依赖 CJS 互操作、部分构建工具（如 Vite）下不可靠，请 default 导入后解构
import 'ljs-tools/index.css'; // main 中引入；只要用到组件就必须引
import LjsTools from 'ljs-tools';
const { LJSLoading, LJSdate } = LjsTools;

TypeScript 与 AI 支持 ​

  • 自带 index.d.ts 类型声明（package.json types 字段已配置），安装后编辑器/AI 直接获得完整类型提示。
  • 配套 AI.md：面向 AI 助手的使用指南（API 速查、最小示例、典型错误对照），AI 编码工具可直接读取。
  • 模块加载不触碰 window/document（Node/构建工具可直接 import，构建期安全）。

详细 API ​

每种能力的参数签名与示例见本栏目各页，或直接查阅 ljs-tools API；精确签名（参数类型/默认值）一律以 index.d.ts 为准。

  • 方法库：基础（LJSbase）、数字（LJSnum）、日期（LJSdate）、表单（LJSfc）、报表数据处理（LJSecDC）、缓存（LJSsession）、加解密（LJScryptoJs）、国密（LJSsm）、颜色处理（LJSrgbC）、URL检测与应用（LJSurl）、elementPlus相关（LJSEl）、水印（LJSWatermark）、脱敏（LJSprivacy）、菜单（LJSmenu）
  • 组件：LJSLoading、分页（Pagination）、右键菜单、区间日期、类型日期、类型区间日期、字典回显卡、粒子运动、内容缩略
  • 全局对象与类：websocket（LJSws）、html转pdf下载（htmlPdf）、Mqtt
